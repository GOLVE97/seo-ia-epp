# SEO + IA Generativa — Protec Industrial MX

## Caso de estudio

Proyecto de portafolio enfocado en el diseño de una estrategia SEO B2B para una empresa ficticia de Equipo de Protección Personal (EPP).

## Objetivo

Diseñar, generar, auditar y optimizar contenido SEO utilizando IA generativa y Prompt Engineering, para posteriormente publicarlo en una página web.
